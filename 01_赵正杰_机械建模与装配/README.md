# 01｜赵正杰｜机械建模与装配

**负责人：赵正杰（赵总）**

本模块收录赵正杰使用 **SolidWorks** 完成的双臂小车三维结构设计、打印件和装配阶段证据。

## 可编辑源文件

为保持 SolidWorks 装配内部的相对引用，源文件与制造导出物整体存放在 `SolidWorks_源文件与制造导出/`；目录内部层级未改变：

- [整机装配](SolidWorks_源文件与制造导出/双臂小车.SLDASM)
- [底盘设计](SolidWorks_源文件与制造导出/小车/)
- [机械臂、夹爪和打印导出物](SolidWorks_源文件与制造导出/机械臂/)
- [Jetson Nano / 开发板固定架](SolidWorks_源文件与制造导出/开发板固定架等/)

`*.SLDASM`、`*.SLDPRT` 为设计源；`*.STL`、`*.3mf` 仅为打印或制造导出物。修改装配前应在 SolidWorks 中检查所有外部引用是否仍能解析。
