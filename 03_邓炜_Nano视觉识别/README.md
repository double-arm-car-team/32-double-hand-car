# 03｜邓炜｜Nano 视觉识别与模型训练

**负责人：邓炜（邓处）——Nano 视觉识别与模型训练**；**帧率优化联调：haimichenha**

本模块保存邓炜完成的 Nano 视觉识别、模型训练相关代码入口和阶段截图。检测工程位于本模块的 `yolov5/`；其中 YOLOv5 上游基础代码、许可证和第三方文件必须保留其原有来源说明，团队提交应明确区分训练产生的模型/配置、自研脚本和上游文件。

## 开发先后与职责边界

1. **邓炜先完成视觉部分的训练与部署**：包括 YOLOv5 工程、模型与检测链路的准备；这部分不归入底盘联调工作。
2. **haimichenha 随后进行视觉运行时帧率优化**：关注引擎、输入尺寸、后处理、显示/采集节拍和日志分析，不承担模型训练或最初部署。
3. 当前归档的项目运行口径是 **YOLOv5 + TensorRT FP32 + 320×320**。阶段性 FP16 文件只说明开发中存在过对比试验，不反向改写最终 FP32 配置。

详见[运行配置与证据说明](运行配置与证据说明.md)。

## 本项目运行配置

- **确认使用**YOLOv5 + TensorRT FP32 检测链路；对应保留入口为 `detect_ultra.py`。
- **模型与输入**`yolov5n_fp32_320.engine`，320×320；脚本中输入、输出主机缓冲区均为 `float32`。
- **保留边界：**目录中同时存有 FP16 引擎和试验脚本，例如 `detect_fast.py`。它们**不是本项目最终运行配置**，不得据此把项目写成 FP16 或混合精度部署；其具体操作归属须以可核验的 Git 历史为准。
- [运行配置与证据说明](运行配置与证据说明.md)记录代码依据、性能结论的取证条件和后续补充方式。
