# Nano SSH 运行时优化试验归档（2026-07-13）

## 归属与阶段

该归档记录 **haimichenha** 在邓炜完成 YOLOv5 训练与视觉部署之后，通过 SSH 连接 Nano 所做的一次运行时帧率优化/诊断试验。其工作边界是推理运行参数、输入尺寸、后处理、采集/显示节拍与日志分析；**不包括模型训练、数据集制作或最初部署**。

这份归档与 `03_邓炜_Nano视觉识别/` 同目录保存，是为了把同一视觉系统的后续优化过程留在可复查的位置；目录位置不改变贡献归属。

## 可复核结果与适用范围

该次试验的原始日志含 428 个每 30 帧输出一次的滚动统计点，覆盖第 30 至 12,840 帧：`fps_avg` 均值 **32.526 FPS**、中位数 **32.938 FPS**，397/428 个统计点不低于 30 FPS。

这是一个**优化阶段的 FP32+FP16 试验结果**，不是当前项目最终 FP32 部署的性能结论。它支持“haimichenha 完成过 SSH 运行时优化与日志化验证”，但不能写成“FP32 已实测 32.526 FPS”，也不能用于替代或转移邓炜的训练与部署贡献。
