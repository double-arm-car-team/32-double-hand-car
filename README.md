# 小型双臂复合机器人系统

本仓库归档小学期双臂小车项目的三部分成果：机械建模与装配、STM32 小车控制与整机联调、Jetson Nano 视觉识别。项目资料、可编辑源文件与阶段性证据均以可追溯路径保存；未附日志或验收判据的图片不应被表述为性能结论。

## 资料使用规则

- SolidWorks 的 `*.SLDASM`、`*.SLDPRT` 是可编辑设计源；`*.STL`、`*.3mf` 是制造导出物。
- 验收视频和照片是阶段证据。成功率、识别指标、轨迹精度或帧率等数值必须附带相应日志、参数或验收判据。
- 底盘、舵机、视觉串口的实际引脚与固件初始化，必须以 [硬件接口与引脚台账](双臂小车/docs/硬件接口与引脚台账.md) 和所选入口 `main` 文件为准。
