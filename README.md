小学期三人协作项目。仓库顶层按实际责任划分为三个模块；每个模块的 `README.md` 是对应资料、代码和验证证据的唯一入口。

| 模块 | 负责人 | 内容 |
| --- | --- | --- |
| [01_赵正杰_机械建模与装配](01_赵正杰_机械建模与装配/README.md) | 赵正杰（赵总） | 基于 SolidWorks 的整机/机械臂三维建模、打印件、总线舵机调试和装配资料。 |
| [02_haimichenha_底盘控制与整机联调](02_haimichenha_底盘控制与整机联调/README.md) | haimichenha | STM32 底盘控制、四轮电机、总线舵机、通信与整机联调。 |
| [03_邓炜_Nano视觉识别](03_邓炜_Nano视觉识别/README.md) | 邓炜（邓处） | Nano/Jetson 视觉识别、模型、检测脚本与串口联调。 |

## 协作与资料规则

- [CONTRIBUTORS.md](CONTRIBUTORS.md)：三人已确认的贡献范围和 GitHub 署名原则。
- [团队分工与协作](团队分工与协作.md)：分支、PR、接口和资料提交规则。
- [资料与证据索引](资料与证据索引.md)：CAD、图片、视频与视觉界面的证据边界。
- `*.SLDASM`、`*.SLDPRT` 是可编辑设计源；`*.STL`、`*.3mf` 是制造导出物。
- 成功率、帧率、精度、闭环效果等性能结论必须附相应日志、参数或验收判据；单张照片不替代测试结论。
