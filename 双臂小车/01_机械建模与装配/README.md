# 01｜机械建模与装配

**负责人：赵正杰（赵总）**

本模块收录双臂小车的结构设计入口、打印件和装配阶段证据。

## 可编辑源文件

为保持 SolidWorks 装配引用关系，源文件未被重命名或移动：

- [整机装配](../双臂小车.SLDASM)
- [底盘设计](../小车/)
- [机械臂、夹爪和打印导出物](../机械臂/)
- [Jetson Nano / 开发板固定架](../开发板固定架等/)

`*.SLDASM`、`*.SLDPRT` 为设计源；`*.STL`、`*.3mf` 仅为打印或制造导出物。修改装配前应在 SolidWorks 中检查所有外部引用是否仍能解析。
