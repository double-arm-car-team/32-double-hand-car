# 双臂小车资料入口

本目录保存双臂小车的机械设计、硬件资料和阶段性证据。为避免破坏 SolidWorks 装配的外部引用，已有 CAD 源文件保持原始目录名称；三个编号目录提供按模块浏览的入口和新增资料位置。

| 模块 | 入口 | 负责人 |
| --- | --- | --- |
| 机械建模与装配 | [01_机械建模与装配](01_机械建模与装配/README.md) | 赵正杰（赵总） |
| 底盘控制与整机联调 | [02_底盘控制与整机联调](02_底盘控制与整机联调/README.md) | haimichenha |
| Nano 视觉识别 | [03_Nano视觉识别](03_Nano视觉识别/README.md) | 邓炜（邓处） |

## 原始设计资料

- `双臂小车.SLDASM`：整机装配源文件。
- `小车/`：底盘基础模型、上下底板、轮组尺寸和铜柱。
- `机械臂/`：肩关节、连杆、夹爪、舵机固定件、子装配与 STL/3MF 导出物。
- `开发板固定架等/`：Jetson Nano 模型、开发板固定架和道具模型。
